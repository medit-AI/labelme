# 뷰 모드 & Polygon Simplify

새로 추가된 기능은 크게 두 가지입니다.

1. **뷰 모드**: 폴리곤 / 마스크 / 원본 이미지 화면을 단축키 하나로 전환합니다.
2. **Polygon Simplify**: AI 폴리곤의 점이 너무 많아 편집하기 어려운 문제를 줄입니다. 원래 모양은 최대한 유지하면서 점 수만 줄입니다.

## 단축키 요약

| 단축키 | 동작 | 메뉴 |
|---|---|---|
| `V` | 뷰 모드 전환: 폴리곤 → 마스크 → 원본 이미지 → 폴리곤 | 보기 > View Mode |
| `P` | Polygon Simplify 켜기/끄기 | 편집 > Polygon Simplify (AI) |
| `Shift+P` | 선택한 폴리곤에 Polygon Simplify 적용 | 편집 > Simplify Selected Polygons |
| `Ctrl+Z` | 적용 결과 되돌리기 | 편집 > Undo |
| `Ctrl+J` | 편집 모드로 돌아가기 | 편집 > Edit Shapes |
| 선 드래그 | 편집 모드에서 폴리곤의 선을 끌면 그 위치에 점이 추가되고 함께 이동 | – |

단축키는 `~/.labelmerc`의 `shortcuts:` 항목에서 바꿀 수 있습니다(`toggle_view_mode`, `toggle_polygon_simplify`, `simplify_selected_polygons`).

---

## 1. 뷰 모드

폴리곤의 외곽선과 점이 경계를 가려서 실제 객체 경계를 확인하기 어려울 때 사용합니다.

`V`를 누를 때마다 다음 순서로 바뀝니다.

| 순서 | 화면 | 편집 |
|---|---|---|
| ① 폴리곤 | 기존 편집 화면 (외곽선 + 점) | 가능 |
| ② 마스크 | 라벨 색을 반투명하게 채워 표시, 외곽선과 점 없음 | 불가 (보기 전용) |
| ③ 원본 이미지 | 도형 없이 이미지만 표시 | 불가 (보기 전용) |

- 보기 전용 모드에서도 화면 이동(가운데 버튼 드래그)과 확대(`Ctrl+휠`)는 됩니다.
- 그리기 도구를 고르거나 `Ctrl+J`를 누르면 자동으로 폴리곤 화면으로 돌아옵니다.
- 다른 이미지로 넘어가도(A/D) 현재 모드가 유지되어 여러 장을 연속으로 검토하기 좋습니다.
- 현재 모드는 상태바에 표시됩니다.
- 마스크 투명도는 `~/.labelmerc`의 `canvas.view_mode_alpha`로 조절합니다(0–255, 기본 128).

## 2. Polygon Simplify

AI(AI-Points, AI-Box, 텍스트 프롬프트)가 만든 폴리곤은 약 1px마다 점이 찍혀 수정하기 어렵습니다. Polygon Simplify는 모양을 최대한 유지하면서 점 수를 줄이고(대략 1/5 수준), 경계를 이미지에 맞춥니다. **기본으로 켜져 있습니다.**

### 사용 방법

- **AI로 그릴 때**: 켜져 있으면 결과 폴리곤에 자동으로 적용됩니다. 툴바의 **Polygon Simplify > Enable** 체크박스나 `P`로 켜고 끕니다.
- **이미 그린 폴리곤**: 폴리곤을 선택하고 `Shift+P`를 누릅니다(또는 Options 창의 **Apply to Selected Polygons**). `Ctrl+Z`로 되돌릴 수 있습니다.
  - 결과의 점이 원래보다 적을 때만 바뀝니다. 손으로 그린 단순한 폴리곤은 그대로 유지됩니다.

### 점이 부족할 때: 선을 드래그해서 점 추가

단순화 후 점이 적어 원하는 위치를 고치기 어려우면, 편집 모드(`Ctrl+J`)에서 **폴리곤의 선을 바로 드래그**하세요.

- 누른 위치에서 가장 가까운 선 위 지점에 새 점이 생기고, 그 점이 마우스를 따라 움직입니다.
- 선을 클릭만 하고 떼면 점이 추가되지 않습니다. 화면에서 3px 이상 끌었을 때만 추가됩니다.
- 도형 전체를 옮기려면 선이 아니라 도형 **안쪽**을 드래그합니다.
- 기존 방식(`Alt+클릭`으로 점 추가, `Alt+Shift+클릭`으로 점 삭제)도 그대로 쓸 수 있습니다.
- polygon과 linestrip에서 동작하고, `Ctrl+Z`로 되돌릴 수 있습니다.

### 처리 순서

```
SAM 마스크 → ① 조각 병합 → ② 경계 보정 → ③ 스무딩 → ④ 점 줄이기 → ⑤ 에지 스냅
```

| 단계 | 하는 일 |
|---|---|
| ① 조각 병합 | 2~3개로 끊긴 마스크를 한 덩어리로 합치고 내부 구멍을 채움 |
| ② 경계 보정 | level-set으로 경계를 실제 이미지 경계에 맞춤 (원래 경계에서 ±8px 안에서만 이동) |
| ③ 스무딩 | 계단처럼 들쭉날쭉한 외곽선을 부드럽게 다듬음 |
| ④ 점 줄이기 | RDP 알고리즘으로 모양에 영향이 적은 점을 제거 |
| ⑤ 에지 스냅 | 남은 점을 가까운 이미지 에지 위로 옮김 |

### 옵션

툴바의 **Polygon Simplify > Options…** 에서 바꿉니다. 바꾸는 즉시 적용되고, 창을 닫으면 저장됩니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| Merge fragments radius | 5 px | 이 값의 약 2배 이하인 틈을 메워 합침 (0: 끔) |
| Boundary refinement | Geodesic | Off / Chan-Vese(밝기 기반) / Geodesic(에지 기반) |
| Refinement iterations | 15 | 경계 보정 반복 횟수 |
| Refinement band | 8 px | 경계가 원래 위치에서 움직일 수 있는 최대 거리 |
| Smoothing iterations | 30 | 스무딩 반복 횟수 (0: 끔) |
| Smoothing weight (w0) | 0.5 | 낮을수록 더 부드러움 (1.0: 끔) |
| RDP epsilon | 2.0 px | 클수록 점이 더 적어짐 |
| Edge snap radius | 3.0 px | 점을 에지에 붙일 때 찾는 거리 (0: 끔) |
| Re-segment with SAM | 꺼짐 | `Shift+P` 적용 시 SAM으로 다시 분할 (아래 참고) |

**자주 조절하는 값**

- 점이 아직 많으면 **RDP epsilon**을 높입니다(예: 3~4px).
- 더 부드럽게 하려면 **Smoothing iterations**를 늘립니다. 스무딩 범위는 약 √(반복 × (1 − w0)) px이고, 기본값은 약 4px입니다. 너무 크면 각진 모서리가 둥글어집니다.
- 옆 구조로 경계가 번지면 **Refinement band**를 줄이거나, 밝기가 비슷한 이웃이 붙어 있다면 **Geodesic**을 사용합니다.

### SAM 재분할 (선택 사항, 기본 꺼짐)

Options 창에서 **Re-segment with SAM**을 켜면, `Shift+P`로 적용할 때 선택한 폴리곤을 감싸는 박스로 SAM을 다시 돌리고 그 결과에 위 후처리를 적용합니다.

- 대충 그린 폴리곤을 객체에 딱 맞게 다시 만들 때 유용합니다.
- 툴바에서 선택한 AI 모델을 사용합니다. 첫 실행은 몇 초 걸리고, 같은 이미지에서 다시 실행하면 즉시 끝납니다.
- **주의**: 손으로 수정한 폴리곤도 SAM 결과로 덮어씁니다. 필요하면 `Ctrl+Z`로 되돌리세요.

### 참고

- AI 결과 형식이 **Polygon**일 때만 적용됩니다. Mask, Rectangle 등 다른 형식에는 적용되지 않습니다.
- 경계가 몇 px 어긋난 경우는 보정하지만, SAM이 아예 다른 영역을 잡은 경우는 고치지 못합니다. 이럴 때는 프롬프트 점을 추가하거나 다시 그리세요.
- 설정은 `~/.labelmerc`의 `ai.polygon_simplification` 항목에 저장됩니다.
